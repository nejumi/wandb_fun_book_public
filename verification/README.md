# ノートブックの実行確認

2026年11月8日、macOSのPython 3.12環境で確認しました。W&Bへ実際に接続し、Run・Artifact・Table・Reportを作成しています。Colab上での実行確認ではありません。

| ノートブック | 確認内容・条件 |
|---|---|
| PyTorchによる実験管理 | Artifactでのデータ受け渡し、学習、2回のSweep、最良Runの選択、テスト評価。各学習は1 epoch、データは200件の学習・40件の検証・40件のテストへ短縮。 |
| マルチメディアの記録 | 画像、COCOのbox、BDDのmask、動画、音声、3D、分子、グラフを記録。nuScenes追加例は実データ未配置のため未検証。 |
| Reports API | サンプルRun・Artifactの作成、Reportの作成・読み込み・更新・結合、ブロック編集後の保存。再確認では作成済みデータを再利用。 |
| セグメンテーション | 元のArtifactのデータを使用。12画像、64×96、1 epoch、事前学習なしで学習し、4画像の予測mask・クラス別IoUをTableへ記録。 |
| RDKitによる化合物分析 | 元のArtifactのデータ、指紋生成、XGBoostの学習、部分構造・分子・予測結果のTable記録。 |

通常のコードセルは計101セルを実行しました。依存関係は別途インストールし、5つのインストールセルは実行対象から外しています。任意のnuScenes追加例の2セルは、データを用意した場合の処理を確認していません。全108コードセルの構文とノートブック形式は検証済みです。

公開するノートブックには、元の学習回数・データ件数を保持しています。上の短縮条件は検証時だけ適用しました。依存パッケージのバージョンとノートブックのハッシュは[JSONの記録](results.json)に記載しています。

実行で見つかった廃止API、テストデータの読み込み先、学習・評価モードの切り替え、RDKitの画像型、Datasetsのboxラベル取得、Reportsの編集例、fastaiの依存関係を補正しています。保存済みの出力は公開ノートブックから除いています。
